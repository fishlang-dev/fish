Rust's ownership, in TypeScript's syntax

Each task is a small Rust program and its translation into Fish, a language with TypeScript's syntax and Rust's ownership rules. The translation has the mistake TypeScript habits lead to; fix it until it prints what the Rust program prints.

If you agree, this page records, for each task: when you open it, each time you compile and the error codes you got, and whether you solved it or gave up, with the time since you opened it. It records no name, address, browser or program text, and nothing ties the record to you. If you don't agree, the tasks work the same and nothing is recorded.
